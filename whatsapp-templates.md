## 1. Greeting message
*Settings → Business tools → Greeting message. Shows when someone messages you for the first time.*

```
Hi 👋 You've reached Run Errands — pickups, deliveries and everyday errands in Alaba, Lagos.

Tell us:
1️⃣ What you need
2️⃣ Your location
3️⃣ When you need it

Send it in any format — even a photo of your list works. We'll reply with the details and a quote
before anything starts.
```

## 2. Away / out-of-hours message
*Settings → Business tools → Away message. Send this only outside your working hours.*

```
Thanks for messaging Run Errands 🙌

We're offline at the moment, but your message is in. We reply as soon as we're back —
usually [WITHIN X HOURS / BY THE NEXT MORNING].

If it's urgent, call or WhatsApp [PHONE NUMBER].
```

## 3. Quick replies
*Settings → Business tools → Quick replies. Type `/` in any chat to insert one.*

| Shortcut | Message |
|---|---|
| `/hello` | Hi 👋 Thanks for reaching out to Run Errands. Please send: what you need, your location, and when you need it done. |
| `/quote` | Thanks! Before we confirm, could you send: the full list (or a clear photo of it), your budget if you have one, your delivery address, and when you need it? |
| `/confirm` | ✅ Confirmed. Here's the plan: [WHAT WE'LL DO] + [COST] + [DROPOFF/PICKUP TIME]. Reply YES and we'll get started. |
| `/pay` | Payment details: [ADD THE CONFIRMED METHOD AND AMOUNT HERE]. |
| `/onway` | On the way 🛒 We'll message you the moment it's done. |
| `/done` | ✅ All done — [HAND IT OVER / DELIVER IT]. Thanks for using Run Errands! If it went well, tell a neighbour about us 🙏 |
| `/noservice` | Sorry, that's not something we take on. Here's what we do handle: groceries & personal shopping, parcel pickup and delivery, pharmacy pickup, laundry pickup and drop-off, document pickup and delivery, and general errands. Anything else, ask first. |
| `/coverage` | We're based in Alaba, Lagos. Send your location and we'll confirm right away whether we can take it on. |
| `/hours` | Our hours are [INSERT REAL HOURS]. Outside those, message us anyway — we'll pick it up first thing. |
| `/thanks` | Thank you 🙏 We'd love to help again. Send us your errand any time. |

asking. Leave the price field empty until pricing is confirmed.
